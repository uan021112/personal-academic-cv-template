This is a personal academic-CV customization for European PhD applications.

- Visual foundation: Xovee Xu, Xovee's CV Template, version 1.0.3 as downloaded
  on 2026-10-29. Source: https://github.com/Xovee/latex-cv
- The original `xovee-cv.sty` is retained without changes. Its MIT copyright
  and permission notice are retained in `LICENSE-Xovee.txt`.
- Management inspiration: LianTze Lim's A Customised CurVe CV:
  https://www.overleaf.com/latex/templates/a-customised-curve-cv/mvmbhkwsnmwv
  That example is CC BY 4.0. No CurVe class, settings file or source macro has
  been copied into this project; the BibLaTeX integration is implemented here.
- BibLaTeX/Biber: https://ctan.org/pkg/biblatex ; https://ctan.org/pkg/biber
